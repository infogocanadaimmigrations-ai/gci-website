GCI WEBSITE — DEPLOY IN 3 STEPS
================================
1) Unzip THIS file (GCI-deploy.zip) -> you get a folder with index.html and the pages.
2) Unzip gci-images.zip (in your Downloads). It contains an "assets" folder.
   Drop that "assets" folder INTO the folder from step 1, so the photos sit at
   assets/img/*.jpg (13 images). You can delete assets/img/PUT-IMAGES-HERE.txt.
3) Go to https://app.netlify.com/drop and DRAG the whole folder onto the page.
   You'll get a live link in ~30 seconds. (No account needed to preview.)

Note: the photos are AI-generated and the facts/tuition figures are estimates —
review before sharing publicly.
